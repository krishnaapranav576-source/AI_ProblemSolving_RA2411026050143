# Problem 14 – Rule-Based Insurance Claim Decision System

## Problem Description

An insurance company needs an automated system to decide whether a claim should be approved or rejected based on predefined logical rules.

The system checks:

* Policy status
* Document verification
* Accident report status

Based on these conditions, the system gives the final decision.

## Algorithm Used

* Rule-Based Inference
* Propositional Logic

## Features

* Accepts claim details from user
* Applies logical rules
* Approves or rejects claim
* Simple and easy console-based system

## Execution Steps

1. Install Python

2. Run the program using:

python insurance.py

3. Enter the following details:

* Policy Active (yes/no)
* Documents Valid (yes/no)
* Accident Reported (yes/no)

4. View final result

## Sample Input

Policy Active = yes

Documents Valid = yes

Accident Reported = yes

## Sample Output

Rule Applied:

Policy Active AND Documents Valid AND Accident Reported = TRUE

Final Decision:

Claim Approved

## Conclusion

The system uses propositional logic to make quick and accurate insurance claim decisions.
